# Cursor AI Clone

A practice project that replicates the UI and basic layout of the **Cursor AI** interface — built as part of the *Assignment-2* in the Cohort Assignments collection.

This project focuses on recreating the look & feel of the Cursor AI web interface using HTML and CSS. Ideal for UI/UX practice, responsive design work, and understanding layout structuring from real products.

---

## Project Structure

cursor-ai-clone/
├── index.html # Main page
├── styles.css # Primary styles
├── assets/ # Images, icons, fonts
└── README.md # Project documentation

## Features

✔ UI layout inspired by Cursor AI  
✔ Navigation components recreated  
✔ Clean CSS styling  
✔ Mobile-friendly responsive design  
✔ Practice for real UI cloning challenges
