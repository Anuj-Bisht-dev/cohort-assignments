# Mintlify Clone

A front-end reproduction of the **Mintlify documentation UI**, built as part of *Assignment-2* in the Cohort Assignments repository. This project focuses on replicating the clean documentation layout, typography, and interactive components using modern HTML and CSS.

---

## About the Project

In this clone, the goal was to:
- Recreate the UI structure with semantic HTML
- Rebuild navigation menus, sidebars, and content sections
- Apply responsive styling similar to the original
- Use CSS to handle layout, spacing, and typography

This project **emphasizes UI practice**, not backend logic.
