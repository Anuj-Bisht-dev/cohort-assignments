# 📚 Cohort Assignments

Welcome to the **Cohort Assignments** repository! This repository contains various project assignments completed during the cohort, showcasing practical applications of web development and related technologies.

## 📂 Repository Structure

| Folder Name | Description |
|-------------|-------------|
| `HTML Resume Page Assignment` | A static HTML and CSS based resume page built as part of the cohort’s UI practice. |
| `cursor-ai-clone` | A clone or practice project inspired by Cursor AI (or similar UI clone) demonstrating layout and interactions. |

> More assignments may be added over time as the cohort progresses.
